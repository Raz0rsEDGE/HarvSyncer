# HarvSyncer

The mod launcher for the AFK Tavern 7 Days to Die server. Before you join, it makes your game's Mods folder match the
server's, then starts the game.

## Download

Download **HarvSyncer.exe** from the [latest release](https://github.com/Raz0rsEDGE/HarvSyncer/releases/latest) and
run it. From then on it updates itself: when a new version is out, it asks before installing it.

Coming from 1.4? Put the new HarvSyncer.exe over your old one. Your server list and settings carry over.

Each release also has a `HarvSyncer.exe.sig` file. The launcher uses it to check that an update really comes from
AFK Tavern. You don't need to download it.
